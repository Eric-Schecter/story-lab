# 风与契约 · 序章 AVG 样片

直接用浏览器打开 index.html，或在本目录运行 `python3 -m http.server 8765`。

点击继续或空格推进，出现选项后点击选择；可回看对白和重新开始比较三条路径。当前为静态立绘，无语音、Live2D动作或存档。

故事直接使用已有编译结果 `../ink/wind-and-contract.json`，由 Inky 所附 inkjs 运行，不另写分支逻辑。更新编译结果后需同步 story.js。AVG只将展示标题“第一章”改为“序章”，不改原有故事与数值。

角色与港口图片复制自本机 live2d-lab/assets/captain 的 harbor-character-v1.png、harbor-background-v1.png，原项目保持不变。inkjs 复制自已安装 Inky 的 node_modules/inkjs/dist/ink.js，许可证保存在 vendor/LICENSE.md。
