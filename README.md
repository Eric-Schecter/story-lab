# Story Lab

Story Lab 用于创作、整理和体验游戏故事，把人物设定、章节剧情、玩家选择与分支后果集中在一起，帮助验证故事如何推动游戏。

在这里可以选择作品与章节，以互动对白的形式试玩故事，也可以查看故事流程图，了解节点、分支和结局条件。

目前收录：

- **《风与契约》**：围绕商人船长艾琳展开的原创故事，主题是商战、背叛与艰难抉择，目前包含序章和第一章。
- **《雾海传说》**：从现有钓鱼游戏整理的六章剧情，串联谋生、港口建设、雾海探索与三种结局，供剧情审阅与体验。

这个仓库既是故事创作的工作空间，也是将剧情接入游戏前的体验原型。作品会随创作与试玩反馈持续完善。
